# BizMetrics 经营数据工作台

这是 BizMetrics 前端，采用 Vue 3、TypeScript、Vite 和 Element Plus。后端、数据库及 API 路径保持原样。

## 本地运行

在 `D:\Code\BizMetrics\frontend` 执行：

```powershell
pnpm install
pnpm dev
```

浏览器访问 `http://localhost:5173`。开发服务将 `/api` 转发到本机 `38080` 端口的后端；生产环境需要同域反向代理，或通过 `VITE_API_BASE_URL` 指定后端地址；先启动后端与数据库，登录和业务数据才可使用。可用 `pnpm build` 检查类型与生产构建，用 `pnpm lint` 检查代码。

## 页面范围

已实现登录、注册、四类总览、流水、账户、预算、票据、报表、税务、审批、组织、福利、绩效、薪酬、用户、政策、设置与备份页面。顶部导航适配桌面，移动端使用底部导航。列表、筛选、详情、主要增改操作和报表使用后端接口；没有数据时展示空状态。
